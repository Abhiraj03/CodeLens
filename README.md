# CodeLens

Most developers using AI coding tools fall into the same trap — you watch the diff, click accept, move on. You stop understanding your own codebase.

CodeLens fixes that. It hooks into Claude Code and visualizes every file write and edit in real time: code lines snap in fast, comments type out slowly with a voice reading them aloud as they appear. When Claude finishes editing a file, you hear a one-sentence summary of what changed and why.

It's not a quiz. It's not a gate. It's just awareness — like having a senior dev narrate while they code.

---

## What it looks like

- **Write:** new file animates line by line into a Monaco editor. Comments glow amber and type at reading pace, voice reads them aloud at the same time. Code lines follow fast.
- **Edit:** existing file loads, scrolls to the change, highlights the old lines red, removes them, and animates the new lines in with the same typewriter logic.
- **File summary:** 4 seconds after the last edit, a short spoken summary plays covering what changed and why.
- **File tree + tabs:** sidebar tracks your project structure. Files glow when touched. One tab per file, VS Code style.

## Requirements

- [Claude Code](https://claude.ai/code) — this hooks into Claude Code's PostToolUse system
- Node.js 18+

---

## Setup

```bash
git clone https://github.com/Abhiraj03/CodeLens
cd CodeLens
npm install
npm start
```

`npm install` automatically registers the hook in `~/.claude/settings.json`.  
`npm start` runs the server at `http://localhost:4006`.

Open `localhost:4006` in your browser before starting a Claude Code session. Click the 🔇 button in the header to enable audio narration.

Then just code normally — CodeLens visualizes everything in real time.

---

## How it works

A PostToolUse hook fires after every `Write` or `Edit` tool call in Claude Code. It POSTs the diff to a local Express server, which pushes it to the browser via SSE. The browser reconstructs the before-state for edits and animates the change.

Voice narration uses the Web Speech API (built into every browser, no API key needed). The file summary is generated by a Claude Haiku CLI call — requires Claude Code to be authenticated, which it already is if you're using it.

---

## Voice

The header has a voice dropdown. **Browser Default** works everywhere out of the box. If you're on Windows or Mac you'll have additional system voices to pick from.

---

## Uninstall

```bash
npm run uninstall
```

Removes the hook from `~/.claude/settings.json`. Delete the folder and you're done.

---

## Why

Vibe coding is a productivity gain with a hidden cost. You slowly lose the ability to read, reason about, and own your code. CodeLens is an attempt to get the speed without that cost.
